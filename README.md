# Heat and Reach: Lagos Island

Heat and Reach is a Python geovisualisation project that investigates where
high daytime land-surface temperatures, concentrated population, and limited
access to public green space overlap in Lagos Island Local Government Area,
Nigeria.

The planned outputs are a reproducible spatial-analysis workflow, a
publication-quality map, and an interactive web application. The project is
being developed as a portfolio piece for an MSc scholarship application.

See [IMPLEMENTATION_GUIDE.md](IMPLEMENTATION_GUIDE.md) for the research design,
data sources, beginner-friendly workflow, milestones, and completion criteria.
